## 📖 درباره پروژه

**وینورا (Vinora)** یک وب‌اپلیکیشن فروشگاهی مدرن است که محصولات خود را از API عمومی و رایگان [DummyJSON](https://dummyjson.com) دریافت می‌کند. این پروژه با هدف نمایش یک تجربه کاربری کامل از یک فروشگاه آنلاین (از مشاهده محصول تا ثبت سفارش) و کاملاً **بدون بک‌اند اختصاصی** طراحی شده است.

تمام داده‌ها (سبد خرید، علاقه‌مندی‌ها، نظرات، سفارشات و اطلاعات کاربر) در **localStorage مرورگر** ذخیره می‌شوند.

---

## ✨ امکانات

### 🛍️ فروشگاه
- نمایش **۱۹۴ محصول** از ۲۴ دسته‌بندی مختلف در قالب کارت‌های زیبا
- جستجوی لحظه‌ای (Live Search) روی نام فارسی و انگلیسی محصولات
- فیلتر بر اساس دسته‌بندی
- مرتب‌سازی بر اساس: **ارزان‌ترین / گران‌ترین / بیشترین امتیاز / نام (الفبا)**
- دکمه **نمایش بیشتر** (بارگذاری مرحله‌ای — ۱۲ محصول در هر مرحله)
- تبدیل خودکار دلار به تومان با نرخ ثابت
- نشان‌دهنده تخفیف، وضعیت موجودی و امتیاز ستاره‌ای

### 📄 صفحه جزئیات محصول
- گالری تصاویر با قابلیت تعویض تصویر اصلی
- نمایش قیمت اصلی و قیمت با تخفیف
- اطلاعات کامل: برند، وزن، ابعاد، گارانتی، شرایط ارسال و بازگشت
- تب‌های جداگانه: **توضیحات / مشخصات / نظرات**
- فرم ثبت نظر با امتیازدهی ستاره‌ای
- بخش **محصولات مشابه** (Related Products)
- بخش **اخیراً دیده‌شده** (Recently Viewed) با ذخیره‌سازی در localStorage

### 🛒 سبد خرید
- افزودن محصول با تعداد دلخواه
- تغییر تعداد و حذف آیتم‌ها
- محاسبه خودکار جمع کل، هزینه ارسال و مبلغ نهایی
- **سیستم کد تخفیف** با دو کد فعال:
  - `SIMIN10` → ۱۰٪ تخفیف
  - `WELCOME50` → ۵۰,۰۰۰ تومان تخفیف
- ارسال رایگان برای خرید بالای ۱ میلیون تومان

### ❤️ علاقه‌مندی‌ها
- افزودن/حذف محصولات با یک کلیک (قلب)
- نمایش لیست علاقه‌مندی‌ها در مودال مخصوص
- شمارنده تعداد آیتم‌ها روی آیکون هدر

### 👤 حساب کاربری و سفارشات
- ورود/ثبت‌نام ساده با نام و ایمیل (بدون احراز هویت واقعی)
- فرم تکمیل سفارش: نام گیرنده، تلفن، شهر، آدرس، کد پستی و روش پرداخت
- دو روش پرداخت: **آنلاین** و **پرداخت در محل**
- صفحه تأیید سفارش با شماره پیگیری یکتا
- **تاریخچه سفارشات** با قابلیت باز/بسته کردن جزئیات هر سفارش

### 📰 مجله
- بخش مقالات با ۵ مقاله پیش‌فرض در قالب کارت‌های جذاب

### 🎨 رابط کاربری
- طراحی کاملاً **راست‌به‌چپ (RTL)** با فونت زیبای **وزیرمتن**
- اعلان‌های **Toast** برای بازخورد عملیات مختلف (موفق، خطا، اطلاع)
- مودال‌های واکنش‌گرا با انیمیشن
- ریسپانسیو کامل برای موبایل، تبلت و دسکتاپ
- پالت رنگی آرام و حرفه‌ای (آبی، فیروزه‌ای و طلایی)

## 🚀 راه‌اندازی

پروژه **بدون نیاز به نصب یا بیلد** اجرا می‌شود:

1. فایل‌های پروژه را دانلود یا کلون کنید:
   ```bash
   git clone https://github.com/your-username/vinora.git
   cd vinora
   ```

2. کافی است فایل `index.html` را در مرورگر باز کنید — **تمام!** ✅

> 💡 **پیشنهاد:** برای جلوگیری از مشکلات CORS در برخی مرورگرها، از یک وب‌سرور محلی استفاده کنید:
> ```bash
> # با Python
> python -m http.server 8000
>
> # یا با VS Code Live Server Extension
> ```

سپس آدرس `http://localhost:8000` را در مرورگر باز کنید.

## 🔌 منبع داده — DummyJSON API

| Endpoint | کاربرد |
|----------|--------|
| `/products?limit=194` | دریافت لیست کامل محصولات |
| `/products/{id}` | دریافت جزئیات یک محصول |
| `/products/categories` | دریافت لیست دسته‌بندی‌ها |
| `/products/category/{category}` | دریافت محصولات یک دسته (برای محصولات مشابه) |

### 🛡️ مکانیزم مقاومت‌پذیری (Resilience)

تابع `fetchJSON` در `app.js` به صورت هوشمندانه عمل می‌کند:
- **۲ بار تلاش مجدد** با فاصله ۷۰۰ میلی‌ثانیه
- **Timeout 12 ثانیه‌ای** برای هر درخواست
- در صورت شکست، به **پروکسی‌های جایگزین** (allorigins و corsproxy.io) سوئیچ می‌کند
- تصاویر نیز از طریق سرویس **wsrv.nl** بهینه و پروکسی می‌شوند

## 🧠 نکات پیاده‌سازی

### 💾 ذخیره‌سازی داده‌ها (localStorage)

| کلید | محتوا |
|------|-------|
| `siminMehrCart` | سبد خرید |
| `siminMehrWishlist` | لیست علاقه‌مندی‌ها |
| `siminMehrUser` | اطلاعات کاربر واردشده |
| `siminMehrReviews` | نظرات ثبت‌شده (بر اساس شناسه محصول) |
| `siminMehrOrders` | تاریخچه سفارشات |
| `siminMehrRecentlyViewed` | محصولات اخیراً دیده‌شده |

### 🌐 ترجمه محصولات

دیکشنری‌های `PRODUCT_TITLES` و `CATEGORY_NAMES` در `app.js` بیش از ۱۵۰ عنوان محصول و ۲۴ دسته‌بندی را از انگلیسی به فارسی ترجمه می‌کنند. تابع `getProductTitle` با منطق **جستجوی دقیق → جستجوی جزئی** عناوین را ترجمه می‌کند.

### 🖼️ پروکسی تصاویر

تابع `proxyImage` از سرویس `wsrv.nl` برای بارگذاری بهینه تصاویر استفاده می‌کند:
```js
https://wsrv.nl/?url=<encoded-image-url>
```
