## 📖 درباره پروژه

**سیمین مهر** یک فروشگاه آنلاین نمونه است که با **HTML، CSS و JavaScript خالص** ساخته شده و بدون نیاز به هیچ فریم‌ورک یا کتابخانه‌ای، تمام امکانات یک فروشگاه مدرن را ارائه می‌دهد. داده‌ها از API رایگان [DummyJSON](https://dummyjson.com) گرفته می‌شوند و نام محصولات به‌صورت خودکار به فارسی ترجمه می‌شوند.

این پروژه برای یادگیری و به‌عنوان نمونه‌کار (Portfolio) مناسب است.
